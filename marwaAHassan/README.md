AI-based calculation agent for invoice processing and automated calculations.

Overview
This project provides an automated calculation agent designed to process invoices, extract relevant data, and perform necessary computations efficiently using Python and modern AI tools.

Requirements
Python 3.10+
Ollama / LLM Framework
Required Python Libraries listed in requirements.txt

Project Structure
calculate_agent.py: Main execution script for the calculation agent.
calculation.py: Core logic and helper functions for processing data.
requirements.txt: Dependencies and package specifications required to run the project.

Getting Started

Install dependencies:
pip install -r requirements.txt

Run the main agent:
python calculate_agent.py
